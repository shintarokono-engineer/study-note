# セキュリティメモ

開発・公開まわりのセキュリティ関連ツール／観点をまとめる。

---

## 1. シークレットスキャン（リポジトリ公開前チェック）

リポジトリを public 化する前に、API キーやトークンがコードや **git 履歴** に混入していないか検査する。過去に一度でもコミットしたキーは `.gitignore` しても履歴に残るため、**履歴全体**を対象にスキャンするのが必須。

**gitleaks** … 正規表現＋エントロピーで秘密鍵・API キーを検出。

```bash
brew install gitleaks
gitleaks detect --source . -v --redact
```

**trufflehog** … 検出したキーを実際に叩いて「今も有効か」まで検証できる。

```bash
brew install trufflehog
trufflehog git file://. --only-verified
```

- 検出の仕組みが違うので**両方**かける。`no leaks found` / `verified_secrets: 0` ならクリーン。
- 検出されたら、まず**キーを再発行（無効化）** → その後に履歴削除（`git filter-repo` / BFG）。順番が大事。
